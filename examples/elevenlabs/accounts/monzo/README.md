# Monzo Bank

## Why this organisation is on the list

Their own complaints return: 67,488 in six months, 64% of them taking longer than three days to close.

Every figure is from a regulator's published report or the organisation's own return, named
on the page with the date it was read.

## The object on the card and the page

The drawn object is **the in-app support thread**, the thing this reader looks at every day. Its tiles carry only
figures from those published files, with one exception.

**One figure on it is not real: a reply that arrives at once.** It is the outcome being sold, drawn on the board so
it can be seen next to what is there now, and it is captioned on the page itself: *"The lit
line is not there yet. The rest is."* The footer names it too. That is a deliberate choice,
not an oversight, and it is the only invented number anywhere on the page.
