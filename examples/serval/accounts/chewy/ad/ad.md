## How it was built

**Headline formula: Pain and outcome.** One of six, chosen before the line was written rather
than picked afterwards to describe what came out.

**The card is an object from Chewy's own world**, with Serval's violet marking the one element
that carries the meaning, and Chewy's own filed number as the biggest thing on it. The test is
to cover the words: the picture alone should say who it is for.

Ad set `Serval - US - Stage1Cold - Unaware - SingleImage - Chewy`, id `AD_SET_ID`, status
**DRAFT**. Nothing was activated and nothing was spent.
