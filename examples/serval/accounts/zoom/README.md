# Zoom

## Why this company is on the list

ServiceNow instance answered at 149.96.253.246, and support.zoom.com is a CNAME to zoomus.service-now.com. One desk, confirmed twice.

Those checks are free and anyone can repeat them. What makes them evidence rather than a trick
is the control: the same check run against a company name that does not exist, which comes back
empty. Without that, a check that answers for anything would prove nothing.
